Judul projek = School Bus Puzzle

Deskripsi = School Bus Puzzle adalah game puzzle sederhana dan menyenangkan dengan tema perjalanan anak-anak menuju sekolah. Pemain ditantang untuk membantu para siswa agar dapat naik ke school bus dan berangkat ke sekolah dengan aman. Dengan gameplay yang ringan dan mudah dipahami, pemain perlu menyelesaikan setiap puzzle untuk membantu anak-anak menemukan jalan menuju bus. Game ini cocok untuk melatih logika, kemampuan memecahkan masalah, dan ketelitian pemain.
